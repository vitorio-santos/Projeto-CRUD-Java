# Projeto-CRUD-Java
Agendamento de horários - CRUD | Java | Spring

A API REST modelo CRUD consiste em um agendador de horários simples para uso diverso, utilizando a linguagem Java,
SpringBoot, e Banco de Dados SQL.

Foi desenvolvida: 
1- Criação e divisão das Entities e as outras respectivas camadas para funcionamento;
2- Definição das Enums com sintaxes básicas;
3- Estrutura com organização e clareza;
4- Modelagem do Banco de Dados SQL.
